# Dev previews (not part of the game)

Nothing in this folder is linked from the game or cached by `sw.js`.

- `robec.js`: level 2, Rue Eau-de-Robec by day. A fixed course played by a scripted autopilot: café tables and chairs, striped awnings to bounce on, balconies, a footbridge over the Robec, house walls to climb, and a finish line.
- `robec-preview.html`: the game with `robec.js` spliced in at the `/*@LEVEL2@*/` marker. Open it and tap "VOIR LE NIVEAU 2". Demo only.
